# 🔤 Hangman Game in Python

Welcome to the classic **Hangman Game**, built using Python! This is a command-line word guessing game where players try to guess a hidden word letter by letter before they run out of lives.

## 🕹️ How to Play

- Choose a difficulty: Easy, Medium, or Hard.
- You'll be shown a hint and the number of letters in the word.
- Guess one letter at a time.
- If you guess incorrectly, you lose a life.
- The game ends when you either guess the word or run out of lives.

## 🚀 Features

- Difficulty levels with different number of lives
- Word bank with hints
- Color-coded terminal output for better UX
- Hangman visual that updates with wrong guesses
- Replay option after each game
